What’s New — redesign variants

Six directions for draw_whats_new(), all in real emery pixels (200×228, shown 2×). The brief: the current screen is flat and doesn’t speak the bespoke language. Every variant below is built only from primitives the app already has — the bespoke_eyebrow at (18,14), the bespoke_row1 value pill, the rounded r=4 accent fill at x=5 w=190, the right-edge scrollbar at x=194, and the footer hint band at y=204 — so none of them need a new drawing idiom.

Where it is now

NOW Fixed 76px header, flat body

A 28 Bold title and a 24 Bold version stacked in a 76px band, then an undifferentiated 18pt list. It is the only screen in the app with no eyebrow, and the section labels are just dim text on the same left margin as the bullets, so NEW / IMPROVED / SYMFONIUM don’t read as structure. Emoji and text share one wrap box, so a second line tucks under the icon.

The variants

A Eyebrow + version pill smallest diff

The literal conformance fix. The 76px band collapses to the standard 40px eyebrow, and the version moves into the same filled pill bespoke_row1 uses for a setting’s value — so the release number reads as the current value of “which version”, exactly like Theme or Keyboard elsewhere. Section labels become accent 14 Bold with a hairline running to the right margin. Bullets get a hanging indent so wrapped lines clear the emoji.

B Section cards

Each section becomes a rounded surface at the exact geometry of a selection row (x=5 w=190 r=4), with its name as an accent pill notched into the top-left corner. The grouping is now a shape rather than a font weight, which is what makes NEW and SYMFONIUM feel like separate answers. Costs one fill per section and reads well on the dark themes; on Default Light the surface has to stay very close to the ground or it turns into a box-fest.

C Accent rail cheapest structure

A 3px accent bar down the left of each section, bullets indented past it. You get the same “these belong together” grouping as the cards for one thin rect per section and no surface color to tune — it works identically on Arcade and Default Light because it is drawn in the accent, which every theme guarantees. The rail also gives the eye a vertical line to track while scrolling, which the current screen completely lacks.

D Ledger rows most native

Scrolling this feels exactly like scrolling the Queue, which is the strongest possible answer to “it doesn’t fit the language”.

Title treatments — keeping the current layout

Same 76px header, same body, only the type changes. Two facts shape the options: the platform ships exactly one serif (DROID_SERIF_28_BOLD), and the version string is pure digits, which is what the LECO faces exist for. The header gives the title a 176px line — the existing code comment records that BITHAM_30_BLACK overflows it, so anything wider than Gothic 28 Bold needs checking rather than assuming. Widths below are approximations in a browser, not device metrics.

T1 Droid Serif one-word change

The whole flourish in a single argument. Against 18pt Gothic body copy a serif title reads as a masthead rather than a label, and it is the only face on the watch that can do that. Same 28px size, same box, no layout change at all. Risk: serifs run wider than Gothic — this is the one that most needs a real width check.

One content note, separate from the visuals

The last three SYMFONIUM bullets — 💥 Search crashes, 🎩 Favorites capped at 40, 🔀 Route wedged on Watch — are fixes, but nothing on screen says so, so they currently read as a list of things the release does. Whichever layout you pick, those want either a FIXED section of their own or a leading verb. Variant D’s accent bar and variant E’s counted pills both make that omission more obvious, not less.
